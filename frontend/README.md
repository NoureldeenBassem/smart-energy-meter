# Frontend — Smart Energy Meter dashboard

Next.js 16 (App Router) + React 19 + Tailwind CSS 4.

Full project documentation, architecture, and setup instructions live in the
[root README](../README.md).

## Development

```powershell
npm install
npm run dev        # http://localhost:3000
```

Requires the backend running on `http://localhost:8000` — the API base URL is set in
`src/lib/api.ts`. The backend's CORS policy (`backend/app/main.py`) allows
`localhost:3000` and `127.0.0.1:3000`.

## Pages

| Route | Purpose |
|---|---|
| `/` | Router gate — redirects to auth, onboarding, or dashboard based on stored state |
| `/auth` | Register / log in; stores the JWT in `localStorage` |
| `/onboarding` | Device pairing — claim a meter and wait for first telemetry |
| `/dashboard` | Live power, predicted bill, budget status, appliance recommendations |

## Notes

- `src/lib/api.ts` — axios instance; an interceptor attaches the bearer token to
  every request automatically.
- `AGENTS.md` / `CLAUDE.md` are generated by `next dev` (see
  `node_modules/next/dist/server/lib/generate-agent-files.js`). This project runs
  Next.js 16, whose conventions differ from earlier versions — consult
  `node_modules/next/dist/docs/` rather than relying on older Next.js knowledge.
